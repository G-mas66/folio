# Folio 1.1.0：Windows 阅读批注与 Agent

用户于 2026-10-10（北京时间）确认方案。本轮仅开发、打包和验收 Windows；不构建、发布 macOS，不改变已发布的 1.0.4 资产。

## 已确认范围

- 高亮、下划线、批注按页码、页面起始位置从上到下和从左到右排序；已有标注、新建标注和重启后一致。PDF 版本有明确标识，不推测版本之间的坐标对应。
- 圈选文字的右键菜单在“批注”旁增加“AI 批注”。先填写问题，再生成“问题＋简要解释”的可编辑草稿，确认保存为普通批注。取消不写入。
- “向 AI 提问”把选区关联到当前会话。显示位置、原文，支持清除或替换。后续“批注到这里”使用该关联；不同会话和文献隔离。
- 聊天 Agent 可准备笔记追加、问题与简要解释批注。未关联选区时检索原文并匹配 PDF 的真实文字位置；多个匹配由用户选择，找不到时保留草稿并允许手选。确认前展示原文、页码和内容；默认自动查找原文 PDF。
- 笔记追加先处理用户未保存的编辑，再确认追加；并发冲突保留草稿、提示用户。确认具备重复提交保护。
- 模型旁加入深度思考和强度设置，按模型记住选择。默认不附加参数，保持服务默认行为。只展示服务返回的公开思考文本或摘要，流式显示、可折叠、聊天历史保留；不伪造思考。批注仅保存问题和解释。

## 实现与验收计划

1. AI 协议参数和公开思考输出 → 检查两种协议实际请求体、流式输出、默认兼容和不支持参数提示。
2. Agent 草稿、定位候选、确认接口与会话关联 → 检查未确认不写入、取消、幂等、跨文献隔离、笔记冲突和旧数据库迁移。
3. 阅读器交互与位置排序 → 使用真实 Electron/PDF 选区验证右键入口、预览、位置选择、保存后刷新、会话隔离和思考显示。
4. 主智能体整合审查 → 运行后端回归、TypeScript 检查、Windows 正式包 smoke 与包内源码核对，输出验收记录及安装包。

三名 GPT-6 Luna / max 子智能体负责 AI 协议、Agent 后端、阅读器前端；主智能体负责 Electron 参数、版本、整合审查和 Windows 验收。完成实现后可增派独立审查和验收子智能体。

## 兼容与边界

继续使用现有配置的 AI 服务、凭据与应用身份。模型支持的开关及强度有差异；明确选择不支持的参数时提示，不静默更改。OCR 图片页或无法提取文字的区域不自动编造坐标。定位预览和确认只操作当前文献。验收使用独立数据目录，不升级、清理或迁移用户实际文献库。
