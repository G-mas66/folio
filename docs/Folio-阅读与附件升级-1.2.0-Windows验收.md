# Folio 1.2.0 Windows 阅读与附件升级验收

日期：2026-10-11。用户批准方案后，由三名 GPT-6 Luna/max 子智能体分别完成后端、聊天界面、笔记与标注映射；主智能体集成并独立审查。仅 Windows，本轮未公开发布。

## 实现内容

- 聊天正文 16px；输入框 14px 圆角；附件入口为无框加号，联网入口为地球图标。模型与推理强度合并选择，并按模型记忆。
- 删除思考展示、开关和黄色能力说明。模型内部推理协议仍用于需要历史推理上下文的服务，界面不展示。
- 右侧提问导航支持跳转、悬停摘要与当前轮次标识；查看历史时保留滚动位置。
- 图片选择、粘贴、拖放；PDF/TXT/MD 文件上传。发送前可预览/移除，聊天历史可重新预览。图片及 PDF 每页渲染图以真实多模态内容块发送，文本内容完整提取。
- 多笔记标签页、创建/改名/删除、Markdown 阅读与编辑、自动保存和旧笔记迁移。笔记与标注区域可拖动分配高度、独立滚动、收起并记忆布局。
- AI 笔记建议可指定现有或新建笔记；确认操作具备版本冲突和重复提交保护。普通保存冲突可合并服务器版本与本地草稿，核对后手动保存。
- 标注按页码及页面位置排序。AI 批注使用统一文本规范化校验；原文、中文及对照视图共享逻辑标注，各视图独立测量位置，匹配到段落时显示标记，无可靠匹配时可手动关联。
- 中转服务明确给出 stop/tool_calls 时，即使未发送 DONE 也按完成处理；真实断流、长度限制与过滤仍保留已有内容并报告未完成。
- 修复更新安装前保存新笔记标签页的请求白名单，以及跨 PDF 引用跳转被当前页数过早限制的问题。

## 使用边界

- 附件每条消息最多 5 个，单文件最多 10MB，文本文件最多 2MB；总附件数据（含 PDF 页图）最多 15MB。PDF 最多 20 页，页图最长边 1024px，完整提取文本合计最多 100,000 字符，超限明确拒绝，不静默截断。
- 实际图片理解和推理强度支持取决于用户所接入模型及中转服务。本轮验证了真实请求载荷，但未调用用户的真实中转服务。
- 跨视图标注针对当前的三份 PDF。翻译重建会清除非主视图缓存并重新匹配；最初创建于旧中文/对照 PDF 的主坐标，不包含完整迁移到重新排版文件的实现。
- 保留已发布 1.1.0 产物于 `out/release-baselines/1.1.0`；本轮未安装到用户正式环境，未改变用户现有安装或文献库。
