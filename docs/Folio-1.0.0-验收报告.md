# Folio Windows 1.0.0 验收记录

本版面向 Windows x64；macOS 保持已发布的 beta.3。

## 改动与证据

| 项目 | 结果 |
| --- | --- |
| AI 接口 | 模型查询、Chat Completions、Responses 的同步与流式请求统一携带 `Folio/1.0`；模拟服务的完整协议会话通过，401/403 分别提示，界面去除 Electron 错误包装 |
| 圈选精度 | 逐个实际字符范围捕获矩形，避免容器和邻近区域；真实鼠标拖选保存 1 个对应矩形，宽度为整 span 的 40.7% |
| 细碎文字 | 一行 40 个独立文字片段产生 156 个原生 Range 矩形，右键菜单正常；行数使用 PDF.js 的页面与文字方向分组 |
| 右键与下划线 | 选中文字时不自动弹菜单；右键提供高亮、下划线、批注、翻译；90° 页面在左侧画线，普通文字在底部，缩放与持久化通过 |
| 翻译小窗口 | 结果在可拖动、可关闭浮窗显示；长译文窗口高 320px、内部可滚动；缩小主窗口后关闭按钮可见；关闭、Escape、切换文献与迟到响应隔离通过 |
| 实际免费翻译 | 打包后端调用真实服务，将公开合成句子 `The measured signal increased by 23.7 percent.` 返回为“测量信号增加了23.7%。”，不使用 AI Key |
| 封面 | 文件夹切回后复用相同封面；观察期间无“载入首页”占位、无再次读取 PDF |

## 验证范围

后端回归 132 项：131 通过，1 项为 Windows 不适用的 POSIX 测试而跳过。存储 13 项及 updater service、下载传输、缓存和真实 updater runtime 契约测试通过。阅读器、AI 协议会话与封面使用最终 Windows 候选程序、独立文献库和假凭据完成 GUI 回归。

隔离 NSIS 升级验收从 beta.4 安装、检查更新、取消下载、重试、重启安装并自动启动 1.0.0，通过后再次正常关闭和打开。合成文献的原文/中文/双语 PDF、分类、笔记、批注、深色主题、模型配置与假凭据保留；重复更新缓存清理通过。验收包装使用独立 appId、安装目录、配置与凭据身份，并将 updater 网络映射到环回服务；生产 main/preload/updater、当前 renderer 及 backend 字节与正式候选对应核对。这不等同于在用户真实文献库上执行升级。

正式包另行严格审计：266 个前端文件与构建输出匹配，后端 EXE 与重新冻结产物匹配；3313 个 PDF 引擎、字体和布局资源与 beta.4 一致，未包含验收 bootstrap。

beta.4 到正式包的真实差分重建通过：传输 19,569,867 字节（含 blockmap/清单），较完整安装包节省 96.12%；没有尝试完整安装包下载，重建 SHA-256/SHA-512 与正式包一致。此项使用正式安装包、真实 electron-updater 及生产下载代码，将 GitHub/代理地址映射到环回服务。

## 实际边界

用户中转站的匿名探测复现了默认 Python 标识被网关以 403 拒绝；更换 Folio 标识后到达正常的“需要 API Key”401 响应。没有使用或读取真实 Key，不能将此表述成用户账号的已认证连通验收。

封面缓存存在当前应用会话中，最多 128 项 / 16 MiB 编码字符串；应用重新启动、首次访问或缓存淘汰后仍需生成封面。翻译依赖免费远程服务可用性；此次只发布 Windows 版本。
