# Folio 1.1.0 Windows 验收报告

开发及验收日期：2026-10-10 至 2026-10-11（北京时间）。本轮只开发 Windows x64；macOS 保持已发布的 1.0.4。本版生成本地安装包，尚未上传公开 Release。

## 完成功能

- 高亮、下划线、批注统一按页码、起始矩形的纵坐标与横坐标排序。已有数据无需重建；原文、中文、双语 PDF 保留版本标识，不推测不同版本的位置对应关系。
- 选中文字右键菜单在「批注」旁提供「AI 批注」：先输入问题，生成可编辑的「问题＋简要解释」，确认后保存普通批注。取消或仅生成预览不写入。
- 「向 AI 提问」将真实 PDF 选区关联到当前会话，显示页码和文字，支持替换、清除与恢复。「批注到这里」沿用关联位置。
- 聊天可准备批注和笔记追加建议。自动批注检索原文、使用 PDF 文本层的实际 Range 坐标；多个匹配需手选，无法匹配时保留草稿并支持手动重选。确认前可编辑，确认幂等，取消不写入。
- 笔记追加前先保存现有编辑；后端核对当前笔记内容，冲突时拒绝覆盖。确认期间的新本地编辑保留为草稿并暂停自动保存，等待手动核对。
- 模型旁提供思考模式及推理强度，按模型记住设置，每次发送使用当时的参数快照。生成时展开服务实际返回的思考文本或公开摘要，可以收起；历史记录保留。服务未返回时不伪造，批注只保存问题与解释。

## 验证结果

- TypeScript 与 UI 构建通过；后端完整回归 159 项：158 通过、1 项 Windows 不适用跳过。新增推理协议和 Agent 测试共 18 项，涵盖两个协议的参数、思考流、工具回合、草稿、确认、冲突、隔离及排序。
- 更新检查、下载回退、差分下载与校验回归通过。
- 真实 Electron 核心流程 5 项通过：右键先提问、确认保存、思考参数经 IPC 传递与持久化、原文位置选择和幂等确认、保存现有笔记后追加。
- 补充桌面流程 7 项通过：模型偏好恢复、选区关联、会话选区和草稿隔离、同位批注、24 个重复引文候选手选、未匹配引用手动重选、取消不写入。
- 旧标记和笔记完整桌面回归通过，包括原文/中文/双语、旋转页面、部分字符和多行坐标、高亮颜色、批注编辑删除、草稿恢复及切换笔记后停止生成。测试文献的原始和库内 PDF 哈希保持一致。
- 三条隔离慢请求复现通过：旧关联不覆盖新关联、旧清除不擦掉新选区、切换会话后旧回包不切回原会话。
- 审查发现并修复新增菜单项导致的底部溢出、关联请求乱序，以及常见写入指令漏识别。最终独立审查无已复现阻断项。

## 验收边界

AI 验收使用本地模拟服务，验证实际应用到后端再到服务的请求、工具回合与返回处理，没有使用用户 Key，也没有声称各商业服务均已在线实测。思考开关、强度及输出受具体模型和接口支持限制；不支持时显示实际服务错误。

只有可提取文字的区域可以自动定位；图片页或未匹配文字必须手动选择可用选区。所有测试均使用独立数据目录，没有安装覆盖用户现有程序，也没有迁移或修改用户实际文献库。NSIS 构建与打包应用验证不等同于在用户真实环境完成升级安装。
