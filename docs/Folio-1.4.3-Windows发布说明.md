# Folio 1.4.3 · Windows 本地 OCR

为扫描页和文字转成轮廓的 PDF 页面接入 Windows 系统 OCR。仅识别缺少文字层的页面，生成带隐藏文字层的副本供全文翻译使用；原始 PDF 不修改。中英文识别在本机离线运行，不需要付费服务或 API Key。

## 使用

1. 安装并启动新版，打开「设置 → 本地 OCR」。
2. 打开「自动进行本地 OCR」，选择「自动选择」或已安装的英语、简体中文识别语言，保存。
3. 已导入且提示提取不完整的英文文献，在右侧详情点击「OCR 后翻译」；中文文献可点击「OCR 识别」。新导入的缺文字页文献会自动识别。
4. 原文始终可在文件存在时打开；中文、双语按钮在对应文件生成后启用。可暂停和继续，已保存的识别副本会保留。

Windows 缺少相应 OCR 语言包时，设置页会说明不可用；请通过系统语言设置安装后刷新状态。「自动选择」优先依据文献已有文字判断中英文。OCR 可能误识别小字、符号和表格，阅读与引用时请核对原文。

## 修复

- 提取不完整状态保留原文阅读入口，以及 OCR 和翻译重试入口。
- OCR 后补齐页级提取记录和问答文本，保留原有段落 ID，避免破坏已有批注锚点。
- 识别失败、取消或语言包缺失时不会发布无效副本，不会标记全文完成。
- 免费翻译服务的 HTTP 500 显示具体服务错误。

## 验收与限制

使用真实 Windows 中英文识别引擎检查扫描文字、轮廓文字与中文页面，核对识别文字、原文件摘要、页数尺寸和渲染像素。Electron 验收覆盖设置保存、原文阅读、OCR 后翻译入口、暂停/继续及识别副本保留。

2026-10-27 验收时，免费翻译服务的 api1 与 api2 检查端点均返回 HTTP 500，实际翻译接口也出现 HTTP 500 或超时。因此本版本已验证本地 OCR 与恢复后的操作流程，未宣称该时点已成功生成整篇中文、双语译文；服务恢复后可继续重试。OCR 本身可离线使用。

本次发布 Windows x64 安装包，源码对应 `v1.4.3` 标签；macOS 继续使用现有版本。
