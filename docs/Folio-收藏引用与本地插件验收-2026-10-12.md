# Folio 收藏引用与本地插件验收

本轮是 Windows 本地开发预览，版本号仍为 1.3.0；没有推送 GitHub、发布软件更新或提交商店审核。

## 已实现的流程

- Folio 书目与文献库共用文件夹，支持筛选、移动、创建、重命名和删除分类。关联 PDF 移动分类后，书目同步；删除 PDF 后保留书目分类。
- 书目保存完整 CSL、出版社、出版地、文献类型、版本和来源。预印本与正式版独立保存，不用正式版字段覆盖预印本。
- 三端共用 citeproc 和同一套 GB/T 7714-2015 顺序编码制、APA 7 样式。元数据修改后确认快照过期，必须重新预览确认。
- 支持补全差异预览，保护手动字段；可按 DOI 添加另一出版版本。UNet++ 会议版和复合姓使用结构化数据回归验证，不从姓氏最后一个词猜测作者结构。
- Chrome/Edge 扩展改用本机 Native Messaging，无须填写配对凭证。支持分类、主页元数据和引用导出信息、DOI 数据核对、引用预览确认、PDF 导入及失败重试。
- Folio 设置提供 Windows 本地 Word 插件安装、修复、卸载。原生插件提供分类检索、引用预览、多篇引用、页码、文档格式与参考文献刷新。未降低宏安全策略或导入信任证书。

## 本地测试方式

关闭正在运行的 Folio，保留整个 `.review/citation-upgrade-preview/win-unpacked` 目录。运行预览目录外的 `启动本地预览.cmd`，它启用本地开发扩展身份；直接运行 exe 默认使用正式扩展身份配置。

在 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载解压缩的扩展”，载入预览中的 `resources/plugins/browser`。打开 Folio 后再打开扩展。扩展标识必须与本机允许列表一致；普通网页不能获得内部认证凭证。

Word 插件从 Folio 设置安装，按提示关闭并重新打开 Word。在实际文档副本中测试插入、刷新、保存重开，再用于正式稿件。安装说明见 `extensions/word/README.md`。

## 验证与边界

- 完整后端测试 199 项：198 通过，1 跳过；随后分类迁移、移动和删除 PDF 的定向回归通过。
- 浏览器测试 18 项、Word 与安装逻辑测试 28 项、共享引擎与注册逻辑测试 3 项均通过，包含冻结后的本机通信程序和身份验证。原生 DLL 编译及命名管道、HTML 格式处理测试通过。
- 实际 Electron、后端、共享引用引擎、本机身份验证和书目界面联调通过，覆盖分类、确认、过期快照和文档渲染。
- 打包后的 Windows exe 与打包后端也已通过上述 7 项工作流联调；最终记录位于 `.review/bibliography-electron-1791765475435/result.json`。文档快照测试使用实际渲染引擎，不代表真实 Word 宿主插入验收。
- 编译后的 Word DLL 状态回归覆盖：写入失败保留旧状态、旧状态删除失败时读取最新版本、损坏与旧控件状态拒绝覆盖、前插引用 ID 与文档顺序一致。预览中的 DLL 与源码构建产物已核对哈希，打包安装器和主进程与最终源码一致。
- 本轮 Word 实际宿主 COM 启动在加载插件前失败，错误为 `0x80080005`。因此，真实 Word 功能区加载、插入与保存重开尚未验收通过；自动化和 DLL 测试不能替代此项。365、2024、2021、2019、2016 是兼容目标，不能宣称全部已实测。
- Edge 商店 ID `gimnkmpfcblogmkkamdlpejgleeiidpb` 已加入正式与开发预览允许列表，并验证注册逻辑。实际商店扩展仍须更新为支持 Native Messaging 的版本，尚未完成商店版连接实测。Chrome 商店 ID 尚待提供。
- DOI 数据源和页面可能缺字段或存在差异。预览确认可以避免静默套用错误版本，但不保证外部数据本身完全准确。普通 PDF 缺 DOI 或期刊不会被强行当作论文。
- 文档保留 CSL 快照；刷新渲染仍需运行 Folio。不能宣称关闭 Folio 后仍能离线重排全部引用。
- 旧 Office.js 插件文档尚未自动迁移到原生插件。检测到旧 Folio 引用控件但没有可读取的原生快照时会停止操作，保留原文档；请勿将“安装成功”理解为旧文档迁移完成。

## 后续发布前必须完成

真实 Word 安装及文档保存重开验收、商店扩展更新与连接实测、Chrome 商店 ID 配置，以及使用者对论文正式版本与预印本的引用预览检查。本轮不把未通过的真实 Word 宿主验收记为通过。
