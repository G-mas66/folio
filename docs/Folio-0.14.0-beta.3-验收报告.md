# Folio 0.14.0-beta.3 验收记录

验收日期：2026-10-09（北京时间）。

安装包源码提交：`f6cf325cceec34a97e6f569f13ead308f6193c6d`。后续提交只补充发布与验收文档。

## 本次改动

- 文献库与阅读页按用户参考图调整分类、列表、工具栏和会话布局，保留原书本波浪图标与 Lora 500 字标。
- PDF 首页缩略图保持原始绘制，修复显示盒尺寸造成的裁切。
- 拖动助手和目录栏时合并鼠标事件，仅预览栏宽；松手后提交布局并重排 PDF，保持阅读位置。
- 深浅主题采用 400ms 颜色缓动，尊重减少动态效果偏好。
- 主题按钮旁新增独立护眼开关，界面与 PDF 显示偏暖，可叠加深色，重启后保留状态。PDF 暖色来自不拦截鼠标事件的显示叠层，不改写文件、画布或导出。

## Windows 检查

源码构建、更新服务检查、主进程语法及 Git 差异检查通过。真实 Electron 环境完成文献标签与分类、流式回答隔离、阅读模式、笔记与批注、三栏及模型、参考布局和窄窗口回归。

护眼检查覆盖开关与主题独立、400ms 中间状态、减少动态效果、PDF 截图像素、原画布不变、文字选择、批注层级、页码和重启保存。正常 PDF 白色采样为 RGB(255,255,255)，护眼显示采样为 RGB(247,237,217)。实际 Windows 生产包重复通过护眼与缩略图检查；开发环境另通过系统标题栏、Lora、深浅主题和跟随系统检查。

包内版本、主进程及入口匹配当前构建，没有测试 bootstrap，公开 beta 更新配置正确。候选包的 3314 个引擎资源文件逐一匹配打包前本地 SHA-256 清单；使用现有冻结资源，本次未重新冻结引擎，也未实施依赖或字体裁减。

另匿名下载并核对公开 beta.2 安装包，解压到隔离目录后比较同一组 3314 个资源，差异为 0。beta.3 的 266 个前端资源也逐字节匹配构建目录。Windows 安装包为 504590410 字节，SHA-256 为 `ed8fffbaea5c198fc8ca1d8312f6f7bbb7583eb46cba99a47c50c03010551c7f`；beta 更新元数据的版本、文件名、大小及 SHA-512 均匹配安装包，上传草稿后的大小与 SHA-256 也一致。

实际生产包的拖动验收通过：79 个采样帧中，拖动期间 PDF 画布尺寸变化为 0；松手后第 4–9 页按新宽度重排，最长采样帧间隔 6.3ms，未观察到长任务。键盘调整、极限栏宽、pointercancel、真实窗口失焦、320ms 内连续窗口缩放和导航后再次拖动、页内位置与重启布局均通过。这是当前候选包的一次测量，没有可靠的旧版性能对比。

失焦验收先关闭 Playwright 原 CDP session 默认开启的焦点模拟，再用第二个真实 Electron 窗口获得焦点，确认原生窗口、webContents、renderer blur 和布局保存。新建 CDP session 的同名开关不足以取消原 session 的模拟，未据此修改生产代码。
