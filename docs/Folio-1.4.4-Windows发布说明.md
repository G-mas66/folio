# Folio 1.4.4 · 网页来源修复

修复论文问答中出现未引用的信用卡、银行和 AI 服务商网页的问题。此前程序会把搜到的全部网页挂到回答下方，并将这些结果继承给后续问题，导致无关网页反复出现。

- 每条回答只展示正文实际使用 `[W数字]` 引用的网页；论文页码引用保持原有行为。
- 旧聊天记录读取时过滤未引用网页，原始聊天内容和数据库记录保留，无需删除对话。
- 历史网页只有在原回答实际引用时才进入后续引用候选；新搜索编号避免覆盖已有历史引用。
- 过滤标题、摘要和地址均未匹配搜索关键词的结果。结果全部不相关时，工具返回无相关结果，允许助手继续根据本文回答。
- 文献问答要求先读本文、围绕用户的研究主题搜索，舍弃无关网页。

## 验收

后端测试覆盖未引用网页排除、有效网页引用保留、旧记录保持不变、历史引用隔离、引用编号不覆盖、无相关结果时继续本文问答，以及中英文搜索相关性。真实 Electron 窗口验收覆盖旧对话中无关链接隐藏、正文所引网页准确展示、论文页码引用保留和不同会话隔离。

关键词匹配只排除明显偏题的结果，不能代替事实核实。网页内容仍属于未经验证的外部资料。Windows x64 安装包与 `v1.4.4` 源码标签一并提供；浏览器扩展保持 1.1.3。
