# Folio 文献收藏扩展隐私政策

生效日期：2026-10-11

本政策适用于 Folio 文献收藏 Chrome／Microsoft Edge 扩展，不代替 Folio 桌面应用或用户另行配置的 AI 服务的隐私政策。

## 读取和使用的信息

扩展仅在用户主动打开、收藏或搜索时处理相关信息，不持续采集浏览记录。收藏时读取当前页面的标题、网址、作者、发表年份、期刊或会议、DOI 等书目信息；Google Scholar 页面可以选择收藏多条结果。用户选择导入 PDF 并授权对应网站后，扩展下载该 PDF。

这些信息用于将用户选中的文献保存到本机 Folio，以及搜索本机已收藏的书目。元数据提取会读取当前页面内容以识别 DOI；扩展不把整个网页正文作为书目发送。

## 存储和传输

扩展配对凭证保存在当前浏览器的扩展本地存储中，不使用浏览器同步存储，不提供给网页脚本。书目、所选 PDF 和收藏目标通过 HTTP 回环地址 `127.0.0.1:37861` 传给本机正在运行的 Folio，并由桌面应用保存。

PDF 下载会向用户授权的来源网站发送请求，该网站可按其自身政策处理网络请求信息。扩展下载请求不携带网站 Cookie、不跟随重定向，单个 PDF 上限为 25 MiB。

扩展本身不向 Folio 云服务器上传书目、PDF 或配对凭证，不嵌入广告或分析统计服务，不出售个人信息。用户在桌面 Folio 中主动调用第三方 AI 或其他联网功能时，相关数据处理由该桌面功能及所选服务商决定。

## 权限用途

- `activeTab`、`scripting`：用户操作时提取当前页面书目。
- `storage`：保存本机连接的配对凭证。
- 本机地址访问权限：连接本机 Folio 插件桥。
- 可选 HTTP／HTTPS 网站权限：用户选择 PDF 后请求对应来源站点的读取授权。

扩展脚本随安装包提供，不从网络加载或执行远程 JavaScript。

## 删除和控制

可在扩展中更换配对凭证，在 Folio 中重置凭证以使旧凭证失效，也可撤销扩展的网站访问权限或卸载扩展。卸载扩展不会自动删除已保存到 Folio 的文献；这些数据可在 Folio 中删除。

## 联系方式和变更

如有隐私问题，可在 https://github.com/G-mas66/folio/issues 联系项目维护者。公开 issue 中请勿提供配对凭证、API Key、私人 PDF 或其他敏感信息。政策变化会通过本页面公布。
