# Folio 阅读与附件升级开发方案

用户已于 2026-10-11 确认预览并授权子智能体执行。仅开发 Windows；本轮先完成实现与本地验收，公开发布另按用户指令处理。

## 已确认设计

- 聊天正文 16 px、输入框 14 px 圆角。联网只显示地球图标，附件入口为无框无底色加号。
- 删除思考开关、思考文本/摘要展示及黄色能力说明；模型与推理强度合并为一个浮层入口，按模型记住强度。
- 聊天右侧短横线导航到各次提问，当前轮次蓝色；查看历史时不强制跟随新输出。
- 图片选择、截图粘贴、拖放，以及 PDF/TXT/Markdown 文件附件；发送前缩略图/卡片、预览、移除，历史保留。图片作为真正多模态输入；文件提取内容而非假装模型看过。
- 每篇文献多笔记标签页，创建/改名/删除、Markdown 阅读/编辑、自动保存；旧笔记无损迁移为第一篇。笔记与标注区域可拖动分配高度、独立滚动、收起。
- AI 笔记建议可选目标笔记或新建，确认前保留编辑，写入具备冲突及重复提交保护。
- 批注保存预览与后端匹配采用一致合理文本规范化，保留文献、页码和选区边界验证。
- 英文、中文、对照共享逻辑标注。各 PDF 使用自身文字层重新定位，不复制坐标。精确匹配绘制选区，段落匹配显示标记，无可靠关联时保留原标注并允许手动关联。
- AI 流式服务明确 stop/tool_calls 完成时兼容缺少 DONE；真实断流、输出上限、过滤仍标记未完成，保留已有内容。

预览位于 `.review/ui-plan-preview/`；图中示例论文和附件为演示内容。

## 分工与验收

1. GPT-6 Luna/max 后端子智能体：笔记迁移/CRUD、附件与多模态协议、流式结束及批注校验 → 独立数据目录测试实际请求载荷、数据隔离、冲突、迁移及负面用例。
2. GPT-6 Luna/max 聊天子智能体：输入框、模型菜单、附件组件、提问导航 → 主智能体集成后验证键盘、发送、粘贴/拖放与滚动保持。
3. GPT-6 Luna/max 笔记子智能体：笔记面板与 PDF 映射 → 验证 Markdown、标签切换、拖动分区，以及真实 PDF 文字层跨视图选区/段落降级。
4. 主智能体：Reader/API/Electron 集成、回归、独立审查、Windows 构建及正式包验收。构建前保留已发布 1.1.0 产物；不触及用户文献库、凭据和安装。

## 接口约定

保留旧单笔记 GET/PUT 的兼容行为，新接口使用稳定 note_id；每个草稿按 paper_id/note_id 隔离。附件 JSON 上传 `{name,mime_type,data_base64}`，归属于 paper/session，聊天使用 attachment_ids。模型协议分别生成实际图片内容块；所有历史附件读取仍校验所属文献/会话。

标注保留原顶层创建位置，新增各视图真实几何缓存和段落关联。缓存不能用于覆盖原始选区，翻译重建后必须重新验证。
