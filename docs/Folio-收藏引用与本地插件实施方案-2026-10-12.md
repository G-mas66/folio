# 收藏引用与 Windows 本地插件实施方案

用户已在本轮明确批准实施，指定 GPT-6 Luna max 子智能体执行，主智能体集成审查验收。此文件记录已批准范围，不另设审批门槛。现有未提交的 Word 与出版字段修复保留。

## 用户流程

论文主页 → 浏览器自动连接本机 Folio → 提取完整书目和 PDF → 选择格式预览并确认 → 选择共用文件夹保存 → Word 按文件夹检索并插入确认的引用 → 动态刷新编号和参考文献。

## 分工

- Folio：书目继承文献库文件夹、顶部书目图标、出版字段与版本身份、已确认引用及来源、补全差异、统一引用引擎、Word 安装/修复/卸载与浏览器本机连接注册。
- 浏览器：Chrome/Edge 自动连接与重连、可信内部认证、主页 metadata/JSON-LD/BibTeX/RIS 提取、PDF 默认导入和失败重试、分类选择、引用预览确认；保留 Folio 图标。
- Word：不做商店版；由 Folio 设置安装本地插件；按分类检索、预览、多篇引用、页码、文档统一格式、编号重排、保存重开和离线快照。

## 数据与安全约束

关联 PDF 的分类以 papers.folder_id 为准，纯书目可分类。保持已有稳定书目 ID，迁移不丢 PDF、作者、手动字段或文档快照。不得默默将预印本替换为正式发表版，不混用不同版本 DOI/页码/年份。复合姓采用权威结构化作者数据，不靠最后一个词强拆。缺关键字段明确显示未确认状态，不以 AI 编造字段。

三端共用 citeproc、同一份 CSL 和 locale，不维护多套格式规则。保存结构化书目、格式、格式化快照、来源、确认状态及指纹，元数据改变则引用过期。Word 管理动态编号与顺序，不把静态 [1] 复制成所有引用的编号。

自动连接不等于取消认证。普通网页不可取得内部凭证或调用本机文献接口；不通过面向任意来源的 HTTP 接口发放凭证。扩展本地可信身份和 Word 本机安装权限独立验证。不得降低系统宏安全策略、无提示批量导入信任证书或修改全局 Trusted Locations。

## 实施与验收

1. 建立统一引用服务和版本/字段/文件夹 API，验证 UNet++ 会议版、预印本、期刊记录及现有数据迁移。
2. 验证 Windows Word 本地安装可行性，选择最少组件的实际可用方案；界面安装不等于真实 Word 可加载。
3. 集成 Folio 分类、预览确认与补全对比，浏览器自动连接和收藏，Word 分类检索插入。
4. 运行适当回归、真实桌面/扩展和 Word 联调；验证首装、重连、来源隔离、编号、保存重开、卸载。
5. 生成本地 Windows 和扩展验收包及真实限制记录；未经本轮明确发布指令不额外发布线上更新或商店审核。

Microsoft 365、2024、2021、2019、2016 是 Windows Word 兼容目标；逐版记录实测结果。Mac 和 Word 商店版不在范围内。
