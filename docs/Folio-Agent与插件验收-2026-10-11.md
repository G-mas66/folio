# Folio Agent 与插件首版验收

本轮实现 Windows 版本，沿用已确认方案；未修改线上更新清单。预览构建仍使用项目当前版本号 1.2.0。

## 功能与入口

- 文献右侧 AI 会话增加“聊天 / 深度研究”。深度研究可选择问题检索、全文、页码范围或关联选区，沿用当前模型和推理强度。
- 研究保存任务步骤、原文证据、引用、调用预算与停止/恢复状态。不展示模型思考。页面图像由阅读器从当前原始 PDF 渲染后发给已识别的多模态模型；未知型号显示未确认图像能力。
- 全文覆盖按每页全部原文片段统计；扫描或无法提取的页会说明限制。引用校验检查编号、摘录和答案正文的结构覆盖，不能代替对结论是否成立的人工判断。
- 阅读助手接入论文精读、科学批判性分析两项 research skills。既有 AI 笔记和批注写入仍保留确认。
- 新增“书目”页，可搜索、补充或纠正标题、作者、年份、期刊/会议、卷期、页码、DOI 和来源。普通 PDF 导入继续不要求这些字段。
- Chrome/Edge 扩展可提取网页和 Google Scholar 结果的书目，选择 PDF 保存到 Folio。缺字段或 PDF 下载失败仍可收藏书目；重复 DOI、PDF 或本地文献关联会核对，保留既有稳定引用 ID。
- Word 加载项支持多篇引用、定位页码、APA 7、GB/T 7714-2015、文档内快照和按文档顺序刷新。明确点击刷新时按稳定 ID 更新 Folio 书目，离线仍可用旧快照重排。手动改过的引用/书目保留并提示。
- 对话区隐藏原生滚动条，保留提问位置导航；滚轮、触控板和跳转继续有效。

## 安装与实际边界

先关闭正在运行的 Folio，再运行本地预览目录中的“阅川 Folio.exe”。请保留完整 win-unpacked 目录。在设置里打开浏览器或 Word 插件安装文件，可按随附 README 配置。普通使用不需要另装 Node。

浏览器扩展选择含 manifest.json 的目录加载。PDF 上限 25 MiB；PDF 链接发生重定向时需打开最终 PDF 地址后再收藏；付费、登录限制或无 PDF 的页面可先保存书目。

Word 是首版侧加载插件：需用户手动准备并决定是否信任 localhost 证书，再设置受信任的共享加载项目录。Microsoft 365、2024、2021、2019、2016 是兼容目标；通过 WordApi 1.1 检测与 ES5 构建适配，不把单元测试或 COM 文档检查当成各版本 Office.js 实机验收。

本机 Word 2021 的隔离 COM 自动化尝试在保存前超时，未生成验收文档；本轮没有取得 Word 保存重开或 Office.js 侧加载的实机通过证据，这两项保留为待验证。

插件分别采用独立配对凭证连接本机服务。桌面内部服务凭证不会交给插件。第三方来源和许可证随包提供。
