# Folio 1.4.5 Windows

免费翻译服务的健康检查偶发 HTTP 500 时，旧版会在标题翻译前将整篇任务标记为失败。本版改用实际翻译请求判断服务可用性，并对 500/502/503/504、超时和临时断网进行有限重试，切换现有备用服务。

- 文献列表直接显示处理失败状态和“重试翻译”，原文可阅读时也不会隐藏失败状态。
- 导入失败提示提供“重试导入”，保留本次选择的文件和目标文件夹。
- 请求期间禁用对应操作，失败后可再次重试，成功后更新任务状态。

Windows x64 用户可下载 `Folio-1.4.5-Windows-x64-Setup.exe`，或在应用设置中检查更新。发布文件附带 `latest.yml`、安装包增量校验文件和 `SHA256SUMS.txt`。macOS 暂维持 1.4.4。

翻译仍依赖外部免费服务；所有端点持续不可用时，任务会保留失败状态并允许之后手动重试。
