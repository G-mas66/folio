# Folio Windows 1.0.1 验收记录

本版修复 PDF 圈选与标记几何，并调整阅读器右侧助手布局。Windows 版本为 1.0.1；macOS 保持 beta.3。

## 修复内容

- PDF 页面容器不再被外框拉高，画布、文字层与标记层使用一致的页面坐标；补齐文字层的尺寸舍入与页面旋转样式。
- 对具有明确列间空白的平面文字层整理阅读顺序，避免左栏跨行拖选同时包含右栏文字；跨栏标题保留在正文之前或之后。
- 捕获选中字符的实际范围，过滤纯空白片段，合并同一行相接或重叠的标记矩形。
- 移除“文献助手”标题行。问答、笔记使用带提示和无障碍名称的图标；会话、新建按钮与当前文献名称合并在一行，提问框底部间距减小。

## 验证记录

TypeScript 与 Vite 构建通过。以下 GUI 检查均使用最终 Windows 1.0.1 生产程序、合成 PDF 和隔离的数据目录完成。

| 项目 | 结果 |
| --- | --- |
| 页面坐标 | 原文、中文、双语与 90° 旋转页的画布、文字层和标记容器边界误差不超过 1 CSS 像素 |
| 双栏拖选 | 真实鼠标跨段落选中左栏第 7、8 行，仅保存目标文字的两条矩形，不含右栏；同页的跨栏标题和页脚保留正确阅读顺序 |
| 相邻两行 | 中文字号 12pt、行距 15pt 的真实鼠标拖选，保存两条互不重叠的标记矩形 |
| 同行重叠 | 三个相互跨接的文字片段合并为一条矩形，不叠加透明高亮 |
| 细碎文字 | 520 个同一行文字片段合并为一个存储矩形，按合并结果应用 512 个矩形上限 |
| 字形与下划线 | 通过画布像素检查高亮覆盖文字、下划线位于字形外侧；普通下划线约距字形底部 0.43px，90° 页面及缩放后通过 |
| 右键、笔记与浮窗 | 部分字符真实拖选、右键菜单、下划线、笔记保存/恢复、批注编辑、翻译窗口关闭/缩放/迟到响应隔离通过 |

| AI 协议回归 | 模拟服务的模型查询、Chat Completions、Responses、流式会话与停止/切换通过；请求保持 `Folio/1.0` 标识 |

正式包审计通过：266 个前端文件与构建输出逐字节一致，main/preload/updater 与源码对应，未包含验收 bootstrap。后端 EXE 与 1.0.0 完全相同，3313 个 PDF 引擎、字体与布局资源也保持一致。本次未重复运行未修改后端的整套单元测试；后端完整回归记录见 1.0.0 验收报告。

1.0.0 → 1.0.1 的真实差分重建通过。10 个安装包 Range 请求传输 3,207,522 字节，含 blockmap/清单的总传输量为 4,261,541 字节，较整包节省 99.1555%；没有全量下载尝试。重建 SHA-256/SHA-512 与正式包一致。此项使用正式安装包与真实 electron-updater，并将 GitHub/代理地址映射到环回服务。

隔离 NSIS 从 1.0.0 安装、检查更新、取消下载、重试、重启安装并自动启动 1.0.1，全程通过；随后正常关闭并重新打开也通过。合成文献的原文/中文/双语 PDF 哈希不变，分类、笔记、批注、深色主题、模型配置与假凭据状态保留。更新缓存保留一份验证过的当前安装包，删除 pending 与重复旧缓存；模拟更新源错误不影响阅读。

安装验收包装使用独立 appId、安装目录、配置与凭据身份，NSIS 安装包缓存也隔离，并将 updater 网络映射到环回服务；包装内的生产 main/preload、266 个 renderer 文件和后端字节与正式候选对应核对。假凭据已清理。这不等同于在用户真实文献库上执行升级。

## 数据与版本边界

本版只调整前端，后端与 PDF 翻译引擎保持 1.0.0 的产物。应用身份、文献库与凭据身份、Windows 更新通道沿用。

验收使用独立目录、合成文献与假凭据，不读取用户的真实文献库或 API Key。此次不发布 macOS 更新。

旧版已保存的标记坐标不按文字搜索自动迁移，以免在重复句子处错配。历史标记若仍有偏移，需要删除后重新标记。
