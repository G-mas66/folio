# Folio 1.4.0 Windows

本版完善“论文主页收藏 → 书目确认 → Word 引用”的流程。

- 书目与文献库共用分类，支持完整出版字段、版本区分和 DOI 补全差异确认。
- GB/T 7714-2015 顺序编码制和 APA 7 共用引用引擎；书目信息修改后，旧引用确认会过期。
- 浏览器扩展支持本机自动连接、分类、引用预览确认与 PDF 导入重试，无须填写配对凭证。已配置 Edge 扩展 ID；扩展仍在商店审核，尚未上架。旧版扩展需更新至本次附带的 1.1.1。
- Folio 设置提供 Windows 本地 Word 插件的安装、修复和卸载；支持分类检索、引用与参考文献刷新。

## 验证与限制

后端 199 项测试：198 通过、1 跳过；浏览器与 Word 自动化测试共 46 项通过，共享引擎与注册测试 3 项通过。原生 Word DLL 的 x86/x64 状态、通信、格式处理回归通过。打包程序与后端的 7 项工作流联调及更新相关回归通过。

**Word 本地插件属于待实机验证功能：本机 Word COM 启动在加载插件前失败，真实 Word 功能区、插入、保存重开尚未验收通过。** 不宣称已完成各 Word 版本兼容性测试。旧 Office.js 文档状态尚不自动迁移，检测到旧引用控件而无原生快照时停止操作并保留原文档。建议先在文档副本中验证。

本次仅发布 Windows x64。浏览器扩展 ZIP 需在 Edge 开发者模式解压加载，或由开发者提交商店更新；软件更新不会自动替用户安装浏览器扩展。
