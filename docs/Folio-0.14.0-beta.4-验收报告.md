# Folio 0.14.0-beta.4 Windows 验收记录

日期：2026-10-09（北京时间）。安装包源码提交：`8cd7ba52fc9d38a002bfc80bbe387a49b35a745b`。

本次只发布 Windows x64，按用户要求未运行 macOS 构建或测试。Mac 继续使用 beta.3。

## 更新行为

Windows 安装包和差分 blockmap 优先经 ghfast.top 传输，失败依次回退 ghproxy.net、GitHub。版本清单与 SHA-512 校验值仍来自官方 GitHub；代理内容无法通过官方校验时不会被接受。差分使用单 Range，取消后不会继续换源，重试期间不会提前将下载界面复位。有旧基包时，坏代理不会触发在该代理上的整包回退；没有旧基包时允许经过校验的代理整包下载。

新版启动后后台限时获取当前运行版本的官方元数据，再校验和整理缓存；下载前等待这次维护完成，不阻塞应用启动。清理只针对已验证为当前已安装版本的精确文件，保留一份当前安装包作为下一次差分基包，删除相同的旧缓存副本及已安装 pending 包与 metadata。未安装的新包、错误校验或未知文件保留；官方清单不可用时跳过，下次启动再尝试。根 blockmap 没有可靠的版本标记，确认当前安装包后移除它，下次按当前版本重新获取，避免错配。

生产 beta.4 的基包为 504594208 字节，约 481 MiB；缓存不会完全归零。未裁减字体、翻译引擎、前端原生绘图库或资源，也未更改文献库、主题与数据库。

生产包的版本、六份桌面模块和 266 个前端文件与构建目录逐字节一致，没有 review bootstrap。3314 个后端、翻译引擎、资源与对应源文件与 beta.3 包的 SHA-256 一致。GitHub provider、beta channel 和旧 updater cache identity 保持兼容。

## 实际安装升级

使用独立 review appId、可执行文件、快捷方式名称及 D 盘安装、数据和 profile 路径运行真实 NSIS beta.3 → beta.4 升级。两份测试包复用生产资源和逐字节相同的主进程、存储、更新服务模块；新版运输与缓存模块也与生产包相同。明确的测试差异是独立身份、入口 bootstrap、网络请求映射 loopback，以及将 NSIS seed 目标重定向 D 盘的模板副本。没有修改生产模板或候选安装包，也没有将候选安装到用户当前环境。

完整一轮通过检测、检查错误不阻塞阅读、实际下载取消、重试、校验、旧进程退出、NSIS 安装和新版自动重启。随后正常关闭并重新打开该已安装新版，核对三份 PDF 的 SHA-256、笔记、批注、文件夹归属、深色主题、模型及隔离假凭据保留。新版报告当前版本无更新。假凭据验收后已精准删除，测试进程已结束。

新版自动重启后保留一份校验通过的安装包，删除已安装 pending 包、metadata 和等价 legacy seed；生产代码中的自动清理路径获得实际验证。review 包含 bootstrap，安装包约 514 MB，不能将其大小或哈希当作正式包。

最初的验收遇到测试快捷方式名称冲突、残留同名文件夹和重启后的 CDP 观察器不可连接。仅修正 review 配置与观察方式后完整重跑，早先失败未算作通过。真实应用仍为 beta.3，真实 C 盘安装器的大小、哈希及原快捷方式时间戳与验收前一致。

## 差分及公网检查

使用两版真实生产安装包、NsisUpdater 6.8.9、GitHubProvider 和本次运输模块完成隔离差分重建。8 次 Range 下载 12106898 字节，另两份 blockmap 为 1051581 字节，版本/feed 元数据 604 字节，总计 13159083 字节，约 13.2 MB（12.55 MiB）。其余内容通过 86 个 COPY 复用，相对 504594208 字节整包减少 97.3921%，没有整包下载尝试。重建 SHA-256、SHA-512 均匹配生产安装包。

公开发布后，通过 curl 的真实 HTTPS 请求从 ghfast.top 取得两份 blockmap 和全部 8 个 Range，总 body 为 13158479 字节。每段均返回正确的 206、Content-Range 和内容，完整重建再次通过 SHA-256、SHA-512。下载、重建与校验单次耗时 17.28 秒，未请求整包；不能据此保证其他网络、Electron 或系统代理下的速度。

[公开 beta.4](https://github.com/G-mas66/folio/releases/tag/v0.14.0-beta.4) 的五份初始附件大小与上传摘要均匹配本地，匿名 beta.yml 与本地逐字节一致，匿名 EXE 开头 Range 与候选相同。标签指向上述安装包源码提交。真实生产 beta.3 在独立数据/profile 环境下从公开 GitHub 检测到 beta.4，新版 beta.4 报告当前已是最新；该公共检测没有启动整包下载或安装。

更新仍是启动或设置页检查，没有服务器即时通知；下载后由用户确认重启安装。旧客户端首次升级仍经原 GitHub 下载通道，也可手动代理下载 beta.4；新版安装后才内置此次代理机制。发布附件包含 Windows 验收摘要、校验清单及公网差分证据，本地完整原始记录保存在 `.review/release-0.14.0-beta.4/` 与 `.review/testfiles/beta4-acceptance/`。
