# Folio 1.4.2 · Windows

本版将文献库调整为紧凑列表。单击一篇文献，右侧显示 PDF 首页封面、中文标题、英文标题（如有）、作者、年份和来源；双击、回车或点击阅读按钮打开 PDF。作者等字段来自已有书目信息，未记录的字段不会猜测补齐。

- 缩小导航、标签、工具栏、设置和助手文字与间距；列表每行 32px，支持键盘上下选择。
- 右侧详情可关闭；原文、中文、双语附件可展开，并可直接打开指定版本或定位文件。
- 新增收藏文献入口；收藏持久保存，最近阅读随打开和切换文献更新。
- 修复旋转页面翻译时内容错位、截断和双语并排尺寸校验失败；按可见页面尺寸校验，同时严格核对页数。原始 PDF 保持不变。
- 修复随应用分发的浏览器扩展因 Native Messaging 身份白名单不匹配而无法连接，并改善连接恢复后的提示。

## 下载与安装

Windows x64 下载 `Folio-1.4.2-Windows-x64-Setup.exe`。运行安装程序，可选择目录；现有文献库与设置继续使用。Windows 更新清单和差分文件一并提供，完整性摘要见 `SHA256SUMS.txt`。

浏览器扩展同步更新至 1.1.3。开发者模式安装请解压 `Folio-Edge-1.1.3-Dev.zip`，在 Edge 扩展页选择「加载解压缩的扩展」。安装并启动新版 Folio 后再连接。商店审核和自动分发不属于此发布。

源码位于本仓库的 `v1.4.2` 标签，GitHub 发布页提供 Source code 压缩包。本次仅发布 Windows 安装包，macOS 继续使用现有版本。

## 验收

使用隔离文献库和合成 PDF，检查真实 Electron 窗口中的封面与书目信息、单击选择、上下键选择、双击阅读、指定 PDF 版本再次打开、收藏、搜索空结果、错误文献操作、详情显隐、浅深色主题、1040×740 最小窗口和设置页。阅读器实际完成 PDF 页面绘制，聊天输入文字为 13px。

另外执行后端、PDF 旋转处理、浏览器注册与扩展、Word 插件回归。测试脚本见 `review/electron_compact_library.cjs`、`backend_tests/test_pdf_engine_rotation.py` 及项目现有测试命令。
