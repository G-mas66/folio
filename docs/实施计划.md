# 实施计划

项目根目录：`D:\个人工作台`。源码、依赖缓存、虚拟环境、构建产物、验收样本、应用 userData 与文献库均限定在 D 盘；npm、pip、Electron 缓存通过本项目命令环境变量指向 `.cache`，不改系统配置。产品不内置 fixture 回复或测试凭据。

## 假设与边界

- 按已确认方案实现 Windows 桌面产品：Electron + React + TypeScript + PDF.js；本地 FastAPI + pypdf + SQLite。后端随安装包打包为独立可执行文件，用户无需安装 Python。
- Chat Completions API Key 只由主进程转发到本机后端，并由 Windows Credential Manager 保存；每次启动生成内存会话令牌，不写入 renderer、数据库或日志。免费翻译使用内置客户端，不携带该凭据。
- PDF 可提取文字才进入翻译队列。扫描、实质内容无法提取或解析失败保留为“需处理”，阻断“可阅读”；真正的空白页允许通过检查，整篇无可用正文则需处理。本轮不加入 OCR。
- 全文按带原页码的段落/片段逐一翻译并落库；仅所有源片段都有非空且正常结束（`finish_reason=stop`）的译文，来源页有效、无缺页后才完成。中断后只处理未完成片段。
- 长文总结按全文顺序分块，逐块保存结果并在全部成功后综合；引用仅接受程序提供的片段 ID，再由程序映射页码。未知来源作为无效引用处理。
- 先完成单机桌面闭环和正式打包；没有用户 API 凭据时用本地隔离兼容 fixture 验证协议与状态机，不宣称真实服务质量已验证。

## 阶段与验收

1. **桌面骨架与安全 IPC**：建 Electron/React/TypeScript 前端、FastAPI 子进程、D 盘数据路径、窗口与安全 IPC。验收：开发模式可启动主窗口和两个互不干扰的阅读窗口；renderer 无 Node 权限；健康检查和重启后 SQLite 可用。
2. **导入、解析与持久化**：实现 PDF 选择/拖放、SHA-256 去重、只复制库内副本、标题编辑与文件名同步、逐页文本/段落/页码入库。验收：源文件哈希不变；同内容去重；同名不同文献不覆盖；无文本页不能进入完成状态；重新导入/重启记录稳定。
3. **AI 凭据与翻译队列**：Chat Completions 配置与连接测试仅用于问答和总结；标题与全文使用内置 PDF2zh-Next 免费客户端、有限并发和持久化队列。验收：AI 请求直接使用所填 URL，不追加路径，并保留用户输入的路径、尾斜线和查询参数；AI Key 不出现在 renderer/SQLite/log，也不发送给免费翻译服务；免费服务错误或空响应不能完成段落；已保存片段恢复时不重发；停止状态不被启动自动恢复，停止后立即继续仍回到队列。
4. **全文翻译与阅读**：按原文片段翻译并逐段保存，完整性检查后解锁阅读；实现 PDF.js、完整中文译文/原文/对照、目录页码入口、阅读进度。验收：未打开论文时自动翻译；所有页面和译文均有来源；任务完成后离线可读；阅读操作不触发翻译请求；阅读窗关闭不影响队列。
5. **自动关联问答与全文总结**：按论文 ID 隔离聊天；实现具体问题原文检索、整篇全文分块摘要、来源 ID 校验与跳页。验收：不上传/粘贴即可总结；方法、结果、附录关键事实均进入覆盖；任何分块失败都不返回伪完整总结；未知引用无有效页码；并行论文问答不串文献。
6. **打包与交付**：冻结 FastAPI 到随包后端，构建 Windows 安装包，写中文使用说明。验收：从最终安装包可启动，无 Python 安装要求；程序、测试、缓存、数据库和用户文献路径留在 D 盘；已完成译文、聊天与页码跨重启保留。

实际命令、结果和未通过项按阶段补记；最终使用 `.review` 样本中的单栏、双栏、长文、同名异内容与无文本页做独立验收，不基于样本内容添加产品特判。
