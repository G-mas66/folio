# Folio 1.4.1 Windows

- 书目支持删除，并在删除前确认。删除书目保留已导入的 PDF、文献库文件夹、同 PDF 的其他版本书目及 Word 文档内的引用快照。
- 修复浏览器收藏 PDF 的权限申请时机；批量收藏先统一申请所选来源权限。
- 同源论文 PDF 使用当前论文页面的下载环境，解决部分出版社页面可下载而扩展后台请求失败的问题。跨域 PDF 继续由扩展后台读取。
- 补充 Springer PDF 链接识别及权限、登录、下载失败提示。

## 更新和扩展

Windows 用户可通过 Folio 内的软件更新安装。浏览器扩展测试使用随本次发布提供的 Folio-Edge-1.1.2-Dev.zip；Folio-Edge-1.1.2.zip 用于上传扩展商店审核。商店版本仍以 Microsoft 审核通过的版本为准。

开发测试时，将 ZIP 解压到固定目录，在 Edge 的 `edge://extensions` 打开开发人员模式，选择“加载解压缩的扩展”，选中包含 manifest.json 的目录。关闭旧版测试扩展，避免重复运行。

PDF 导入需要用户原本具有下载权限；不会绕过订阅、机构登录或购买限制。下载限制为 25 MiB。

本次未改变 Word 插件；真实 Word 主机的安装及插入、保存、重开验收仍未完成，不将单元测试等同于 Word 全流程验证。
