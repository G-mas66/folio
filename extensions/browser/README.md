# Folio 浏览器扩展

此 Manifest V3 扩展面向 Chrome 和 Microsoft Edge，可收藏普通网页、Google Scholar 搜索结果以及网页 PDF。网页元数据不完整时仍可保存；PDF 下载为可选操作。

## 安装

1. 启动 Folio 桌面工作台。
2. 打开 Chrome 的 chrome://extensions 或 Edge 的 edge://extensions。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择 Folio 提供的浏览器扩展文件夹（其中包含 manifest.json）。
5. 将“Folio 文献收藏”固定到工具栏，点击图标。
6. 在 Folio 的“设置 → 浏览器与 Word 插件”复制配对凭证，粘贴到扩展并配对。

更新代码后，在扩展管理页点击扩展的刷新按钮。卸载扩展可在同一管理页完成。

## 收藏

在普通网页打开扩展，可以检查提取到的标题、作者、年份、来源和 DOI，并选择 Folio 文件夹。字段缺失不会阻止保存；可在 Folio 书目中修改记录。

在 Google Scholar 搜索结果页打开扩展，可以勾选多条结果。每条结果可只保存书目，也可选择检测到的 PDF。打开网页 PDF 时，扩展会提供当前 PDF 作为导入候选。

浏览器会在首次读取某个 PDF 来源时询问站点访问权限。只有选择 PDF 并允许访问后，扩展才会以不带站点 Cookie 的请求读取它。扩展仅接受 HTTP(S) 公网链接，不跟随重定向；如果 PDF 链接会跳转，请先在浏览器中打开最终 PDF 地址，再从扩展收藏。单个 PDF 上限为 25 MiB，读取时也会检查流大小和超时。下载或导入失败会显示在状态中，书目仍会保存。

## 连接与隐私

扩展只连接桌面工作台的本机插件桥 127.0.0.1:37861，并仅调用健康检查、书目搜索、文件夹列表和收藏接口。配对凭证保存在当前浏览器的扩展本地存储中，不会交给网页内容脚本。PDF 正文通过本机桥发送给已打开的 Folio，再由桌面应用导入；扩展不会把 PDF 上传到其他服务。

如果 Folio 设置页重置了插件凭证，请在扩展中选择“更换配对凭证”并重新配对。若提示无法连接，请确认桌面工作台正在运行。
