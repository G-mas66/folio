# Folio 文献收藏扩展隐私政策

生效日期：2026-10-12

本政策适用于 Folio 文献收藏 Chrome／Microsoft Edge 扩展，不代替 Folio 桌面应用或用户另行配置的 AI 服务隐私政策。

## 读取和使用的信息

扩展不会持续采集浏览记录。用户点击扩展后，它读取当前标签页的标题、网址、作者、发表年份、期刊或会议、DOI 和页面提供的结构化书目信息，用于预览或保存到本机 Folio。用户可以在 Google Scholar 页面选择要收藏的结果，并在保存前核对 DOI 查询到的元数据。

用户选择 PDF 或 BibTeX／RIS 文件作为导入来源时，扩展会在请求读取该来源前，通过浏览器询问对应网站的可选访问权限。扩展只请求用户选中的文件，并在本地解析或交由本机 Folio 解析。PDF 和引用文件请求不携带站点 Cookie、不跟随 HTTP 重定向，并限制文件大小和请求时间。

点击“核对 DOI 信息”时，Folio 会将该 DOI 查询 Crossref 或 DataCite，并把返回的元数据交给扩展供用户选择。该查询会向元数据服务披露这个 DOI。扩展不会把一般网页正文、书目或 PDF 发送给 Crossref 或 DataCite。

## 存储和传输

扩展使用 Native Messaging 与本机 Folio 通信，不要求用户复制或输入配对凭证，也不在浏览器扩展存储中保存内部会话令牌。Folio 仅向明确登记的受信任扩展 ID 注册本机 Native Messaging 主机；主机再通过当前 Windows 用户的命名管道和本地随机密钥连接 Folio。网页内容不能调用这条连接。

扩展发送给本机 Folio 的内容包括用户选择保存的书目、可选 PDF、文件夹选择和用户确认的引用格式。Folio 在本机应用内保存这些内容。扩展本身不向 Folio 云服务器上传书目或 PDF，也不嵌入广告或分析统计服务。

读取用户选中的 PDF 或 BibTeX／RIS 文件时，浏览器会向对应来源站点发送请求。该网站可能按自己的政策处理该网络请求。扩展请求不携带站点 Cookie、不跟随重定向，并限制文件大小和请求时间。

## 权限用途

- `activeTab`、`scripting`：在用户点击扩展后读取当前标签页内容。
- `nativeMessaging`：通过受信任的本机原生消息主机连接 Folio。
- `alarms`：维护后台连接状态。
- 可选 HTTP／HTTPS 网站权限：用户选择读取 PDF 或 BibTeX／RIS 文件后，请求对应来源站点的访问权限。

扩展不申请默认的全站读取权限；可选网站权限仅在用户发起文件读取时请求。扩展脚本随安装包提供，不从网络加载或执行远程 JavaScript。

开发预览版仅向允许列表中的开发扩展 ID 注册连接。Chrome Web Store 和 Edge Add-ons 的正式扩展 ID 尚未配置；生产自动连接需在商店 ID 确定后加入生产允许列表并发布新版本。

## 删除和控制

用户可在浏览器中撤销扩展的网站访问权限或卸载扩展。卸载扩展不会自动删除 Folio 已保存的文献；用户可在 Folio 中删除这些数据。Folio 可在应用中重置本机连接密钥。

## 联系方式和变更

如有隐私问题，可在 https://github.com/G-mas66/folio/issues 联系项目维护者。公开 issue 中请勿提供 API Key、私人 PDF 或其他敏感信息。政策变化会通过本页面公布。
